# Bot Specifications: Antigravity Sentinel

## Core Features
- **V1: Verification**: Links Telegram ID to a verified LinkedIn profile.
- **V2: Keyword Monitor**: Tracks terms like "delay", "force majeure", "shortage".
- **V3: Knowledge Query**: RAG-based bot that searches community archives for solutions.

## Tech Stack
- **Language**: Python (Telethon/Aiogram).
- **Intelligence**: OpenAI/Gemini API for sentiment analysis and summarization.
- **Database**: Supabase (PostgreSQL) for member verification and archive metadata.
