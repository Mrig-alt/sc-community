# Security

This repository contains community documentation, frameworks, templates, and planning materials.

## What Should Not Be Here

- Personal phone numbers or private email addresses of members
- CVs or professional profiles shared in confidence
- Confidential company data, internal case studies, or proprietary information
- Passwords, API keys, or access tokens of any kind

## If Something Was Committed by Mistake

Contact the repository owner immediately. The file will be removed from history.

## Member Data

Member information (names, backgrounds, contact details) is stored separately and privately. It is never committed to this repository.
