# SC Deep Dive — Session Template

## Pre-Session (48 hours before)

- Confirm the case-bringer and their problem
- Send a one-line brief to all attendees: "This session: [problem in one sentence]"
- Prepare 2–3 diagnostic questions in case discussion stalls

## Session Agenda

| Time | Activity |
|------|----------|
| 0–5 min | Welcome — what problem, why it matters, who is in the room |
| 5–10 min | Intros — name, SC background, one word for what you want from this session |
| 10–40 min | The case — case-bringer presents, group asks clarifying questions, then diagnoses |
| 40–50 min | Synthesis — what framework applies, what would we do, what is still unknown |
| 50–60 min | Wrap — next session, any new role assignments, Telegram prompt for the week |

## Facilitation Notes

- Keep the case-bringer talking for no more than 10 minutes before opening to the group
- Push for specifics — "what exactly happened" not "what generally tends to happen"
- If the group drifts to abstract, redirect: "how does this apply to the case in front of us?"
- End with a concrete output: what is the one thing we learned today?

## Post-Session (within 48 hours)

Publish the case write-up to `/updates/` on GitHub and share a summary on LinkedIn.
